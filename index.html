verified_user

プライバシー・ファースト設計

Enhancer 4 Google は開発者サーバーを一切持たず、すべてのデータをあなたのブラウザ内とGoogle公式環境のみで安全に処理します。

dns 外部サーバー送信ゼロ

入力したプロンプト、チャット履歴、カテゴリ構成、APIキーが開発者や第三者のサーバーへ送信・収集されることは一切ありません。

vpn_key ユーザー主導の直接連携

Gemini API や GAS Webアプリ連携は、ユーザー自身が設定したキー・URLに対してブラウザからHTTPSで直接通信を行います。

lock Chrome Storage ローカル管理

すべての設定値は Chrome 標準の Storage API のみに保存され、いつでもJSONエクスポートやアンインストールによる完全消去が可能です。
