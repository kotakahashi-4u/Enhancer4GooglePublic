プライバシーポリシー

最終更新日: 2026年11月24日（v2.0.0 対応）

「Enhancer 4 Google」（以下、本拡張機能）は、ユーザーのプライバシーとセキュリティを最優先に設計されています。本ポリシーでは、Chrome ウェブストアのユーザーデータポリシーに準拠し、本拡張機能におけるデータの取り扱いについて説明します。

要約: 開発者は独自の外部サーバーを一切保有しておらず、お客様の個人情報、閲覧履歴、チャット内容、プロンプト、APIキー等を収集・保存・送信することは一切ありません。すべての処理はお使いのブラウザ内、またはお客様ご自身が指定した公式エンドポイントとの直接通信のみで完結します。

fact_check1. 取り扱うデータとブラウザ権限の目的

本拡張機能は、お客様が有効化した各機能を実現する目的でのみ、ブラウザ内で以下の情報および権限を使用します。

  • 設定情報・カテゴリ構成データ (storage): 各機能のON/OFF状態、カスタムステータス、および Gemini / Gemini Notebook のカテゴリ整理データをブラウザ内の chrome.storage.sync / chrome.storage.local に保存するために使用します。
  • 対象ページのUI拡張およびWebクローラー (scripting / activeTab / host_permissions): Gemini、Gemini Notebook、Google Chat、Google Slides、Google Apps Script、Google アプリランチャー上へのUI改善適用、アカウント言語切替操作の補助、およびお客様が指定したURLのMarkdownソース生成（Webクローラー機能）のために使用します。
  • ファイルの自動変換・保存 (downloads / offscreen): お客様がダウンロードした特殊画像（HEIC/WebP等）をブラウザ内の隔離環境（Offscreen / Sandbox）でJPGへローカル変換する処理、および生成したMarkdown・ZIPファイルを保存するために使用します。

sync_alt2. 外部通信とAPIキー・GAS URLの取り扱い

本拡張機能は開発者のサーバーとは一切通信を行いません。以下の機能をお客様が任意で利用した場合に限り、ブラウザから対象エンドポイントへHTTPSによる直接通信を行います。

  • Google Apps Script 向け Gemini アシスタント機能: お客様ご自身が設定画面に入力した Google AI Studio の Gemini APIキーを使用し、Google公式の Gemini API（generativelanguage.googleapis.com）へ直接リクエストを送信します。
  • Google Slides PDF取込・ドキュメント万能PDF変換機能: PDFの解析・画像化はブラウザ内（PDF.js）でローカル処理され、お客様ご自身がデプロイして設定画面に登録した Google Apps Script（GAS）WebアプリURLに対してのみデータを送信します。

取得・処理したデータを広告配信、行動追跡、第三者への提供・販売に使用することは一切ありません。

lock3. データの保存・保護と削除方法

  • ローカル保存のみ: すべての設定値、APIキー、カテゴリデータはお客様の Chrome ブラウザ内のストレージ領域にのみ保存され、開発者がこれらを閲覧することは技術的に不可能です。
  • バックアップと完全削除: 設定データはいつでも設定画面から .json ファイルとしてエクスポートできます。また、Chrome ブラウザから本拡張機能をアンインストールするだけで、ブラウザ内に保存されたすべての設定データが自動的に削除されます。

Privacy Policy

Last Updated: November 24, 2026 (Updated for v2.0.0)

"Enhancer 4 Google" (hereinafter referred to as "this extension") is designed with user privacy and security as our highest priority. This policy explains how data is handled in compliance with the Chrome Web Store User Data Policy.

Summary: We operate zero developer servers. We DO NOT collect, store, transmit, or sell your personal information, browsing history, chat messages, prompts, or API keys. All processing occurs locally within your browser or via direct HTTPS communication with official Google endpoints or your own self-hosted Apps Script URLs.

fact_check1. Data Handled & Permissions Usage

This extension uses browser permissions strictly locally and solely to provide the features explicitly enabled by the user:

  • User Preferences & Category Data (storage): Used to store feature toggles, custom chat status templates, and folder organization metadata for Gemini and Gemini Notebook locally via chrome.storage.sync and chrome.storage.local.
  • UI Enhancements & Web Crawler (scripting / activeTab / host_permissions): Used to apply UI improvements on Gemini, Gemini Notebook, Google Chat, Google Slides, Google Apps Script, and the Google App Launcher, assist with one-click Google Account language switching, and crawl user-specified web pages to generate Markdown files locally.
  • Local File Conversion & Downloads (downloads / offscreen): Used to convert downloaded images (such as HEIC/WebP to JPG) inside an isolated browser Offscreen/Sandbox environment and save generated Markdown or ZIP archives to your device.

sync_alt2. Direct External Communications

No user data is ever sent to the developer or third-party analytics services. Network requests occur directly from your browser only when you actively use the following optional features:

  • Gemini Assistant for Google Apps Script: Uses your own Gemini API key (configured by you) to communicate directly with Google's official Generative Language API (generativelanguage.googleapis.com).
  • PDF Import & Universal Document Conversion: PDF rendering is performed locally in your browser via PDF.js, and slide/document payloads are sent exclusively to the Google Apps Script Web App URL deployed and configured by you.

We never use any user data for advertising, profiling, surveillance, or data brokerage.

lock3. Data Storage, Protection & Deletion

  • Local Browser Storage Only: All settings, API keys, and category structures remain inside your browser's Chrome Storage API. It is technically impossible for the developer to view or access them.
  • Backup & Complete Removal: You can export your settings as a .json backup file at any time. Uninstalling this extension from Chrome immediately removes all locally stored extension data.
